Important Distinction

TerraPulze is strongest in the exploration intelligence workflow — data ingestion → interpretation → target generation → evidence/reporting — rather than being a complete mining ERP, field-management system, finance platform, or regulatory case-management system.

All API endpoints listed are Proposed endpoints — recommendations for the product/API architecture, not claims that these routes already exist.

The Central Product Insight

Document TerraPulze not as "software that replaces the geologist", but as:

An exploration intelligence and evidence platform that connects raw geological data to defensible exploration decisions.

Current strongest workflow: Data → Interpretation → Target → Evidence → Report

Next major product opportunity: Data → Interpretation → Target → Field Validation → Assay → Target Update → Exploration Decision → Investment/Regulatory Decision

That second loop is where the six personas begin to share the same underlying evidence, rather than each persona working from separate spreadsheets, PDFs, GIS projects and reports.

1 · All Ideas Shared (Concepts, Not Conversation)

Every distinct idea surfaced in the meeting, grouped by theme — the problem, the solution, expert drilling knowledge, and strategic direction.

🧗 The Problem Being Solved

  • Manual data-point picking is slow, stressful and requires rare experts
  • Finding satellite imagery online requires combining multiple ray-bands — heavy workload
  • Justifying "why drill here, not there" means manually sitting down and writing reports
  • Exploration teams wander the ground instead of knowing exactly where to drill

💡 The Core Solution

  • Feed data in → intelligent system ranks drill targets automatically
  • Each target gets a confidence percentage (e.g. "99% confidence this hole yields this resource")
  • System explains why — with the science behind it included
  • Query it further for deeper explanations
  • Remove a data point → rerun on the fly → results in under a minute

📥 Data Inputs (Multi-Source Fusion)

  • Sentinel-2 — vegetation & moderation bands
  • Copernicus DEM — terrain data
  • LOAA magnetic data (geophysics)
  • Lithology data
  • Geochemistry — collected on the ground (soil/auger)
  • C-Log and any other user data points
  • Geology from "Wakusta's" + One Geology (run separately or together)
  • Protected areas — from the Forestry Commission
  • Roads / access layers

🖥 System Capabilities (Live Demo)

  • Hosted & live — access granted on request
  • Overview: # of targets, area measured, analyses run, avg target scope
  • Project details + team activity slots (everything logged)
  • Base maps: light / dark / satellite / terrain / hyperspectral
  • Layer toggles with "eye" button for data provenance explanations
  • Depth estimation — only added when probability is high; omitted when unsure
  • Analyses run in the background while you do other things
  • Click a drill target → score (e.g. 72%), cluster cells, depth, coordinates

📐 Grid & Layout Logic

  • Targets appear in grid form — point, point, point on the map
  • No wandering: cut lines across the points → baseline + cross-lines
  • Access-aware: system factors existing roads/paths for optimal rig placement

⚙️ Drilling Expertise — Deviation

  • Precision drilling: the smaller the hole, the shorter it must be, or it deviates
  • 165mm hole → beyond ~12 m stays true; 76mm hole → deviates past ~8 m (granite is hard, bends rods)
  • Angular holes are better than vertical — already at an angle
  • Drill string becomes a "strain" — must control the feed
  • Historical case: 1,010 m hole drilled like a parabola, 13°, corrected by controlling feed; remote-controlled from Australia (1999), depth checked every 30 minutes
  • Controlled deviation can be used deliberately to steer into ore

🕳 Down-Hole & Underground Ideas

  • Target ≠ starting point — both are targets (collar position + ore position)
  • Soil & auger work locates the zone; soil data stretched to predict vertical zones (~150 m vertical, 165 m down)
  • Deep drilling: eventually locate targets underground rather than from surface (15–18 months lead time)
  • Underground drilling needs extreme specificity — you may drill holes you weren't meant to

🗺 Scope Definition (Expert Feedback)

  • Define scope precisely: does the work end at "put the hole here," or extend to profile/angle?
  • Collar deviation exists even in current practice — plan 60°, end up slightly up/down
  • Structural data was missing from the demo — it's what angle-planning is derived from
  • Future capability: "put hole here, drill at this angle, this depth, expect this deviation/error margin"
  • Must become robust to compete with GIS tools like Hillfrog, KTIs

🏛 Governance & Minerals Commission Vision

  • Companies report through the system, not paper reports dropped at the office

4 · How an Exploration Team Navigates This

A practical playbook for a team adopting TerraPulze — from first login to a validated drill program.

🚀 Quick Start Day 1

  1. Request access from the TerraPulze team — the system is already hosted and live.
  2. Login and create your project; add team members so every activity is tracked.
  3. Upload your geochemistry data (soil/auger points) as the overlay.
  4. Toggle in magnetics, terrain, lithology and geology layers — all pre-hosted.
  5. Run your first analysis — targets and confidence scores in under two minutes.

🔁 The Iteration Loop Days 1–5

  1. Run the analysis with all data points → note the target ranking.
  2. Drop one layer (e.g. Wakusta's geology) → rerun on the fly.
  3. Read the system's explanation of how that layer changed the analysis.
  4. Add it back, drop another (e.g. magnetics) → rerun → compare.
  5. Click each surviving target — interrogate the score, depth, coordinates and reasoning.
  6. Converge on the target set you trust, with defensible reasons for each.

🎯 From Targets to a Drill Program Week 2

  1. Switch the base map to terrain + toggle roads — find where a rig can actually go.
  2. Lay a grid (baseline + cross-lines) across the chosen targets.
  3. For each collar position: apply the diameter-vs-depth deviation table (Section 3).
  4. Pick the angle (angular holes deviate less) and the right rig/rod size for the ground.
  5. Assign the feed-control strategy — who monitors depth, when to correct.
  6. Export the auto-generated full report — justification included, no manual writing.

📊 Validate & Scale Month 1+

  1. Run historical data from a known deposit through the model — does it predict what was actually found?
  2. Conduct a live trial (100–300 m band) with a partner such as Gold Fields; write a memo with terms.
  3. Feed actual drill results back — close the prediction-vs-reality loop.
  4. On disturbed ground, field-verify before trusting model predictions.
  5. For small/medium operators (e.g. Chinese medium-scale), use the system to demonstrate how soil, local grids, structural and grab-sample data integrate.
  6. Connect to the Minerals Commission plug-in — report digitally, stay monitored, stay compliant.

⚠️ Team Watchpoints

  1. Know the fundamentals first — the gaps in the software come from not knowing how exploration is done today.
  2. Pair the tech team with a dedicated geologist experienced in down-hole work.
  3. Define your scope: does your use end at hole positioning, or extend to angle/profile planning?
  4. Remember collar deviation exists even at a planned 60° — always carry an error margin.
  5. Push for structural data in the demo — it's the basis of angle planning.
  6. Benchmark against Hillfrog / KTIs-class GIS robustness before pitching multinationals.

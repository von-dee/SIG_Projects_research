# **PART 3: SYSTEM DOCUMENTATION**

### **1. Architecture Overview**
AureusLIMS utilizes an **Edge-Cloud Hybrid Architecture** to solve the remote mining camp connectivity problem.

*   **Edge Node (Lab Server):** A local micro-server or ruggedized PC physically located in the mine's lab. Runs the full application stack. Guarantees 100% uptime even if the mine's satellite internet goes down.
*   **Cloud Node (HQ Server):** Hosted on AWS/Azure. Aggregates data from multiple mine sites for corporate reporting. Accessible by executives and geologists.

### **2. Technology Stack**
*   **Frontend (UI):** React.js with Progressive Web App (PWA) capabilities. Allows installation on any tablet/PC without app store approval.
*   **Backend:** Node.js or Python (FastAPI). Python is highly recommended for future AI/ML data science integration.
*   **Edge Database:** PostgreSQL (relational) for structured assay data, paired with CouchDB or PouchDB for resilient local offline sync.
*   **Cloud Database:** PostgreSQL on AWS RDS.
*   **Hardware Middleware:** Custom Node.js/Python scripts using pySerial to parse RS232/TCP-IP streams from scales and analytical instruments.

### **3. Data Flow & Integration**
1.  **Instrument -> LIMS:** XRF/AAS finishes an analysis -> outputs a file (CSV/XML) or stream (RS232) -> Middleware parses the stream -> extracts Sample ID, Au grade, Ag grade -> pushes to local PostgreSQL DB.
2.  **Edge -> Cloud Sync:** A background cron job checks for internet -> if connected, packages new DB records as encrypted JSON payloads -> pushes to Cloud Node -> Cloud Node acknowledges receipt -> Edge marks records as "synced".

### **4. Security & Compliance**
*   **Role-Based Access Control (RBAC):** Roles defined as Tech (data entry only), Chemist (workflow execution), QA/QC (approval/rejection), Admin (system config).
*   **Data Integrity:** All records are append-only. If an assay result is corrected, the system saves the old value, the new value, the user ID, and the timestamp in a secure audit log.
*   **Compliance:** System designed to meet ISO 17025 and LBMA guidelines for data retention and traceability.

# **PART 4: BUSINESS MODEL**

### **1. Value Proposition**
"We provide enterprise-grade LIMS accuracy for gold mines and assay labs at a fraction of the cost, with a modern interface that works even when the internet doesn't."

### **2. Target Customer Segments**
*   **Primary:** Mid-tier gold mining companies (10M - 50M oz reserves) who cannot justify $1M+ Thermo Fisher implementations.
*   **Secondary:** Independent, commercial assay labs servicing multiple junior explorers. (High throughput, price-sensitive).
*   **Tertiary:** Junior exploration companies needing basic, cheap sample tracking.

### **3. Revenue Streams (Disruptive Pricing Model)**
Instead of massive upfront licensing, AureusLIMS will use a SaaS model with tiered pricing:

*   **Tier 1: The "Lab Starter" (For Juniors/Explorers)**
    *   $1,000 / month.
    *   Cloud-only, up to 5 users, 5,000 samples/month, basic reporting.
*   **Tier 2: The "Enterprise Edge" (For Mid-Tier Mines)**
    *   $4,000 / month.
    *   Includes Edge Server deployment (offline capability), unlimited users, 50,000 samples/month, full instrument integrations, QA/QC modules.
*   **Tier 3: "Pay-Per-Assay" (For Commercial Labs)**
    *   Base fee of $500/month + $0.25 per sample processed. Highly scalable; aligns your revenue with their success.
*   **Professional Services (One-Time):**
    *   "White-Glove Integration Fee": $10,000 - $25,000 to cover on-site deployment, hardware driver customization, and staff training.

### **4. Go-To-Market (GTM) Strategy**
1.  **The "Shadow" Pilot:** Offer a struggling commercial assay lab a 3-month free trial of the MVP. Prove that it reduces TAT and errors compared to their Excel spreadsheets. Use their success as a case study.
2.  **Conference Dominance:** Attend major mining conferences (PDAC in Toronto, Mining Indaba in Cape Town) with a ruggedized tablet, demonstrating the offline UI and live scale integration on the exhibition floor.
3.  **Hardware Partnerships:** Partner with analytical instrument vendors (e.g., Olympus, Mettler Toledo). When they sell a $100k XRF machine to a mine, they recommend AureusLIMS as the preferred, plug-and-play software integration.
4.  **Open API Marketing:** Publicly publish your API documentation. Show mining companies that unlike Thermo Fisher, AureusLIMS will never trap their data; it integrates seamlessly with their existing ERPs (SAP, Oracle) and geological modeling software (Datamine, Leapfrog).

### **5. Cost Structure (To Ensure Profitability)**
*   **Fixed Costs:** Developer salaries, cloud hosting (AWS/Azure), legal/IP costs.
*   **Variable Costs:** Customer onboarding/training time, travel to remote mine sites for deployment, custom driver development for obscure legacy lab hardware.

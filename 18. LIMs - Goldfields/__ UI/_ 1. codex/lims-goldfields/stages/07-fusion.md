# 07 — Fusion

**Role:** Assay technician  
**Record:** [Furnace batch sheet](../forms/07-furnace-batch-sheet.md)  
**Outcome:** A traceable lead button for every batch position, validated alongside controls.

## User flow

1. Create/select a furnace batch and choose the approved fusion method, furnace, tray, and crucible positions.
2. Add assay charges and required standards, blanks, and duplicates. Record each material’s position; do not leave gaps ambiguous.
3. Add the prescribed flux to each charge and record flux lot/amount where required.
4. Load crucibles, start the furnace program, and record actual run parameters and operator.
5. On completion, recover/identify the lead button for each sample and transfer it to cupellation with the batch and position retained.

## Form fields entered

Batch ID, method, furnace ID/program, tray ID, crucible position, charge/control IDs and types, flux lot/amount, load/start/end timestamps, temperature profile reference, operator, button ID/condition, and exceptions.

## Controls and hand-off

- Batch controls are mandatory and must travel through the same relevant process route.
- Tray/crucible position links each button to its original charge and supports contamination investigation.

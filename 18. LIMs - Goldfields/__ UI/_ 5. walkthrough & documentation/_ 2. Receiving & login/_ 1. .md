# Implementation Plan — 02 Receiving & Login (Sample Intake Log LIMS)

Implement the full, production-grade **02 — Receiving & Login** workflow for the Receiving Clerk role in AurumLIMS, matching the official LIMS form specification (`Sample intake log (LIMS)`), user flow steps 1–6, batch handling rules, barcode generation, mass & balance logging, discrepancy & hold accountability, and hand-off to the drying queue.

## User Review Required

> [!IMPORTANT]
> - **Immutable Lineage**: The lab sample ID & barcode (e.g., `AU-LAB-26-00891` / `AU2600891`) becomes the primary operational identifier across all downstream lab steps (drying, crushing, pulverising, fire assay), while the original field sample ID (`GH-Fld-26-002314`), hole ID (`A2E-114`), and depth interval (`84.0–86.0 m`) are permanently preserved as immutable lineage metadata.
> - **Accountable Intake Holds**: Any bag with discrepancies, broken seals, damaged condition, or depth mismatches is placed on intake hold. Holds strictly require resolution notes, communication references, and photo records before release to drying.

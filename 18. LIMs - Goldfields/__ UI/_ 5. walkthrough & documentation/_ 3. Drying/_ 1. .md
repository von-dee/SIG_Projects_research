# Implementation & Walkthrough — 03 Drying (Drying Log Sheet & Oven Run Tracking)

Implement the full, production-grade **03 — Drying** workflow for the Prep Technician role in AurumLIMS, matching the official LIMS form specification (`Drying log sheet`), user flow steps 1–5, oven batch handling, moisture loss calculations, balance integration, deviation & hold accountability, and hand-off to crushing.

---

## 1. Role & Record Overview

- **Role:** Prep technician
- **Record:** `Drying log sheet` (`forms/03-drying-log-sheet.md`)
- **Outcome:** A dry, weighed sample linked to the oven run and verified for constant mass before jaw crushing.

---

## 2. Completed User Flow Steps

1. **Scan Accepted Lab Sample & Method Confirmation:**
   - Scan or load incoming sample (`AU-LAB-26-00891`) from the Receiving login queue.
   - Confirm standard SOP method version (e.g. `SOP-PRP-01 v2.4 (105°C ± 5°C Standard Core/RC)`, `SOP-PRP-02 (95°C High-Sulfide)`, `SOP-PRP-03 (110°C Fast-Track GC)`).
   - Verify container compatibility (Stainless Steel Drying Trays up to 250°C).

2. **Chamber Loading & Positioning:**
   - Load sample into designated industrial oven (`Oven #1 Despatch LAC` or `Oven #2 Memmert UN750`).
   - Assign shelf/rack position (`Rack A · Shelf 1 · Pos 01`) and tray identifier (`T1-01`).
   - Start or join active batch run (`DRY-RUN-2026-042`).

3. **Cycle Parameters & Telemetry Recording:**
   - Record target setpoint (105 °C) and actual chamber temperature (104.8 °C) tracked via thermocouple sensor `TC-OV1-PRIMARY`.
   - Record cycle start timestamp and planned duration (4.0 hours).

4. **Unload Inspection & Dry Mass Weigh-in:**
   - At completion of the 4-hour cycle, inspect physical condition (dry & free-flowing vs. clumped/scorched).
   - Weigh sample on qualified balance (`BAL-METTLER-04` with valid calibration certificate).
   - Capture dry mass (e.g. `2.78 kg` from wet reference `2.96 kg`).

5. **Automated Moisture Loss & Deviation Controls:**
   - LIMS automatically calculates moisture loss:
     $$\text{Moisture Loss \%} = \frac{\text{Wet Mass} - \text{Dry Mass}}{\text{Wet Mass}} \times 100$$
     - *Example:* $\frac{2.96 - 2.78}{2.96} \times 100 = 6.08\%$ ($0.18\text{ kg}$ loss).
   - **Quality Control Rules:**
     - Conforming Range: $0.2\% \le \text{Loss} \le 15.0\%$.
     - Anomaly Flag 1: Loss $> 15.0\%$ (Excessive moisture anomaly / drilling slime contamination).
     - Anomaly Flag 2: Loss $< 0.2\%$ (Suspicious zero loss / dry core).
     - Anomaly Flag 3: $\text{Dry Mass} > \text{Wet Mass}$ (Impossible gross gain / tare mismatch).
   - Interrupted runs or anomalous samples trigger an automatic **Hold** with mandatory accountable resolution.

6. **Technician Sign-Off & Hand-off to Crushing:**
   - Record operator badge (`PREP-012`) and digital timestamp.
   - Mark sample as `Completed & Ready for Crushing` with onward routing target (`Crushing Queue Jaw-01 · Tray C-01`).

## 3. Data Architecture & Form Specification

### `DryingLogRecord` (All 16 Form Fields Implemented)

| # | Field Name | Description & Specification |
|---|---|---|
| 1 | **Drying run ID** | Unique batch identifier (e.g., `DRY-RUN-2026-042`) |
| 2 | **Lab sample ID** | Accessioned sample barcode (e.g., `AU-LAB-26-00891`) |
| 3 | **Oven ID / Shelf position** | Chamber & rack coordinate (`Oven #1 · Rack A · Shelf 1 · Pos 01 / T1-01`) |
| 4 | **Method version** | SOP standard (`SOP-PRP-01 v2.4 (105°C ± 5°C)`) |
| 5 | **Target temperature** | Configured setpoint (`105 °C`) |
| 6 | **Actual temperature / ref** | Live thermocouple reading (`104.8 °C` via `TC-OV1-PRIMARY`) |
| 7 | **Start date/time** | Timestamp when chamber reached temperature (`2026-08-26 12:00 GMT`) |
| 8 | **End date/time** | Timestamp when tray was safely unloaded (`2026-08-26 16:15 GMT`) |
| 9 | **Planned / actual duration** | Residence time (`4.0 h` planned / `4.25 h` actual) |
| 10 | **Wet mass reference** | Immutable mass captured at receiving login (`2.96 kg`) |
| 11 | **Dry mass / unit** | Post-drying mass captured on calibrated balance (`2.78 kg` / `2780 g`) |
| 12 | **Balance ID** | Analytical balance used with calibration tag (`BAL-METTLER-04`) |
| 13 | **Sample/container condition** | Inspection tag (`Dry & Free-Flowing`, `Clumped`, `Scorched`, etc.) |
| 14 | **Deviation / hold reference** | Deviation code (`NONE`, `EXCESS_MOISTURE_LOSS`, `DEV-DRY-2026-018`) |
| 15 | **Prep technician / sign-off** | Responsible operator badge & sign-off (`Kofi Boateng · PREP-012`) |
| 16 | **Completion status** | Operational disposition (`Complete` / `Hold` / `In Oven` / `Queued`) |

## 4. Key UI Components & Modals

1. **`DryingPage.tsx`**:
   - Live SCADA-style oven telemetry strip for Oven #1, Oven #2, and Oven #3.
   - Comprehensive KPI indicators (Active runs, Samples dried today, Avg moisture loss %, Active holds).
   - Tabbed workspace: **Drying Log Sheets**, **Oven Batch Runs**, and **Receiving Queue**.
   - Live search, filtering by status (`In Oven`, `Completed`, `On Hold`, `Queued`), and oven selector.

2. **`DryingLogSheetModal.tsx`**:
   - Full interactive execution of the LIMS Drying Log Sheet.
   - Automatic moisture loss percentage & mass delta engine.
   - Color-coded QC tolerance gauge.
   - Balance calibration validation and zero-check display.
   - Digital sign-off and print-ready log export.

3. **`DryingRunBatchWizardModal.tsx`**:
   - 4-step wizard for batch oven loading, shelf assignment, and rapid dry mass weigh-in.
   - Direct staging and hand-off to jaw crushing.

4. **`DryingOvenMonitorModal.tsx`**:
   - Real-time 2D visual chamber shelf layout (4 shelves $\times$ 6 tray slots).
   - Live thermocouple thermal stability curve with duty cycle telemetry.

5. **`DryingHoldResolutionModal.tsx`**:
   - Accountable resolution of anomalous drying samples (Re-dry, Re-weigh, Senior Metallurgist Override, or Quarantine).

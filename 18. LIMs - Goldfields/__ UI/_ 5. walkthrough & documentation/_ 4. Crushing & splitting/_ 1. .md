# Implementation & Walkthrough — 04 Crushing & Splitting (Crush / Split Worksheet & Coarse Reject Retrievability)

Implement the full, production-grade **04 — Crushing & splitting** workflow for the Prep Technician role in AurumLIMS, matching the official LIMS form specification (`Crush / split worksheet`), user flow steps 1–5, jaw crusher reduction to < 2 mm, riffle splitting with mass balance & recovery % calculations, unique child IDs (`-W` and `-R`) preservation without replacing parent IDs, mandatory coarse reject archiving location enforcement, 1:20 routine granulometry sieve checks, and hand-off to the pulverising queue.

---

## 1. Role & Record Overview

- **Role:** Prep technician
- **Record:** `Crush / split worksheet` (`forms/04-crush-split-worksheet.md`)
- **Outcome:** A defined coarse split proceeds; a retrievable reject is retained.

---

## 2. Completed User Flow Steps

1. **Scan Dried Sample, Inspect Readiness & Equipment Recording:**
   - Scan parent dried sample barcode (`AU-LAB-26-00891`, dry feed mass `2.78 kg` / `2780.0 g`) from the Stage 03 Drying queue.
   - Verify sample dryness and constant mass check.
   - Select primary jaw crusher (`JAW-CRUSH-01` Boyd Hydraulic Dual-Jaw #1, `JAW-CRUSH-02` Essa JC2000, `JAW-CRUSH-03` TM-100).
   - Select riffle splitter (`SPLIT-RIFFLE-01` Jones 12-chute Stainless Steel Splitter or `SPLIT-ROTARY-01` Essa Rotary Cascade Divider).

2. **Crusher Method Execution & Carryover Cleaning Controls:**
   - Configure SOP standard: `SOP-PRP-04 v2.1 (Primary Coarse Jaw Crushing < 2 mm, 95% passing)` or `SOP-PRP-05 (High-Grade Quartz with Barren Wash)`.
   - Verify jaw gap aperture setting (nominal `1.8 mm – 2.0 mm` checked with feeler gauge).
   - Record cleaning and carryover controls:
     - `Barren Quartz Flush` (500 g barren quartz pulverized through jaws between drill holes to scrub carryover).
     - `Compressed Air Blowout` (high-pressure nozzle blowout between routine samples).
     - `HEPA Vacuum Extraction` (hood dust cyclone active).
   - Technician toggles and verifies cleaning completion prior to sample feed.

3. **Riffle-Splitting, Child ID Generation & Mass Balance:**
   - Riffle-split coarse crushed material into:
     - **Working Split (to Pulverising):** Unique child ID `AU-LAB-26-00891-W` (mass `254.2 g`, nominal ~250 g).
     - **Coarse Reject (to Retained Archive):** Unique child ID `AU-LAB-26-00891-R` (mass `2512.4 g`).
   - **Quality Control & Lineage Rule:** The working split and reject are generated as permanent children of the dried sample, **never replacing the parent ID**.
   - **Live Mass Balance Engine:**
     $$\text{Total Recovered Mass} = \text{Working Mass} + \text{Reject Mass} = 254.2 + 2512.4 = 2766.6\text{ g}$$
     $$\text{Mass Loss} = \text{Feed Dry Mass} - \text{Total Recovered} = 2780.0 - 2766.6 = 13.4\text{ g}$$
     $$\text{Mass Recovery \%} = \frac{2766.6}{2780.0} \times 100 = 99.52\% \quad (\text{Loss } 0.48\%)$$
   - **Tolerance Thresholds:**
     - Conforming (Pass): Recovery $\ge 98.0\%$ (Loss $\le 1.5\%$).
     - Warning: Loss $1.5\% < \text{Loss} \le 3.0\%$ (Requires technician justification note).
     - Hold / Anomaly: Loss $> 3.0\%$ or negative loss ($\text{Recovered} > \text{Feed}$).

4. **Bag, Label, and Archive the Retained Coarse Reject:**
   - Bag coarse reject in heavy-duty polyethylene archive bag with tamper-evident security seal (`SEAL-REJ-89412`).
   - Record and allocate mandatory storage location:
     - **Warehouse:** `Main Core Shed B`
     - **Rack & Shelf:** `Rack CR-04 · Shelf 2`
     - **Box & Slot:** `Box BX-2026-118 · Slot 01`
   - **Quality Control Rule:** A missing reject location **blocks worksheet completion**.

5. **Granulometry QA Check & Hand-Off to Pulverising:**
   - Routine 1:20 QC Sieve Analysis on 2.0 mm Tyler 9 mesh screen (100.0 g sample aliquot $\to$ 97.4 g passed = 97.4% passing $\ge 95.0\%$ target).
   - Operator sign-off with badge ID (`PREP-012 Kofi Boateng`) and digital timestamp.
   - Forward working split (`AU-LAB-26-00891-W`) to the **05 Pulverising Queue**.

## 3. Data Architecture & Form Specification

### `CrushSplitRecord` (All 14 Form Fields Implemented)

| # | Field Name | Description & Specification |
|---|---|---|
| 1 | **Worksheet ID** | Unique crush/split run worksheet code (e.g., `WS-CS-2026-088`) |
| 2 | **Crusher/split run ID / member position** | Run identifier and sequence index (`CRUSH-RUN-2026-054` / Position 1) |
| 3 | **Parent dried sample ID** | Accessioned sample barcode (`AU-LAB-26-00891`) with immutable field & hole lineage |
| 4 | **Crusher ID / run ID** | Primary jaw crusher (`JAW-CRUSH-01 Boyd Hydraulic Dual-Jaw #1`) / `CRUSH-RUN-2026-054` |
| 5 | **Crusher cleaning check** | Cleaning protocol (`Barren Quartz Flush` 500 g, `Compressed Air Blowout`, `HEPA Vacuum`) |
| 6 | **Splitter ID** | Splitter unit (`SPLIT-RIFFLE-01 Jones 12-Chute Stainless Steel` / 1:8 ratio) |
| 7 | **Working split ID / mass** | Generated child aliquot (`AU-LAB-26-00891-W` / `254.2 g`) |
| 8 | **Reject ID / mass** | Generated child coarse reject (`AU-LAB-26-00891-R` / `2512.4 g`) |
| 9 | **Total recovered mass / material-balance** | Recovered mass (`2766.6 g`) / Recovery (`99.52%` Pass $\ge 98.0\%$) |
| 10 | **Reject bag/seal ID** | Tamper-evident seal barcode (`SEAL-REJ-89412`) |
| 11 | **Reject shelf / box / position** | Warehouse coordinate (`Main Core Shed B · Rack CR-04 · Shelf 2 · Box BX-2026-118 · Slot 01`) |
| 12 | **Operator / timestamp** | Prep technician badge & sign-off (`Kofi Boateng · PREP-012` / `2026-08-26 13:45 GMT`) |
| 13 | **Deviation or loss explanation** | Accountable explanation text for any material loss $> 1.5\%$ or hold flag |
| 14 | **Completion status** | Operational status (`Split Completed` / `Hold` / `In Crusher` / `Ready to Crush`) |

## 4. Key UI Components & Modals

1. **`CrushingPage.tsx`**:
   - SCADA-style equipment telemetry strip for Boyd Jaw #1, Essa Jaw #2, and TM-100 Jaw #3.
   - 4-card KPI strip: Active Crusher Runs, Splits Sent to Pulverising, Avg Mass Recovery %, Crushing Holds.
   - 4 Tabbed Workspaces:
     - **Crush / Split Worksheets**: Interactive table with live search, status filters, mass recovery gauges, reject location badges, and action buttons.
     - **Crusher Batch Runs**: Overview of runs with throughput, cleaning verification, and granulometry stats.
     - **Incoming Dried Queue**: Real-time queue from Stage 03 Drying with 1-click "Load into Crusher".
     - **Coarse Reject Archive**: Storage inventory locator for all archived rejects.

2. **`CrushSplitWorksheetModal.tsx`**:
   - Full interactive execution of the LIMS Crush / Split Worksheet.
   - Parent lineage card displaying immutable hole ID, depth interval, dry feed mass, and moisture loss %.
   - Real-time dual-input mass balance calculator with visual recovery gauge and anomaly alerts.
   - Crusher & Riffle Splitter configuration with cleaning check verification.
   - Child IDs (`-W` and `-R`) generator.
   - Coarse reject storage location picker with auto-allocation helper (enforces mandatory location rule).
   - Routine 2.0 mm Sieve Analysis QA tab.
   - Dual barcode label preview & printing for working split envelope and coarse reject bag.

3. **`CrushingBatchWizardModal.tsx`**:
   - 4-step batch workflow wizard:
     - **Step 1:** Multi-sample selection from drying queue.
     - **Step 2:** Equipment setup, jaw gap selection, and cleaning protocol verification.
     - **Step 3:** Fast-entry table for rapid working split mass & reject mass entry with live recovery calculation.
     - **Step 4:** 1:20 routine granulometry QA check, technician sign-off, and onward dispatch to Pulverising.

4. **`CrushHoldResolutionModal.tsx`**:
   - Accountable resolution of held samples (material loss $> 3.0\%$, sieve oversize fail, missing reject location).
   - Corrective actions: Senior Metallurgist Justification & Release, Re-Split from Retained Coarse Reject, Re-Crush Oversize Fraction, or Quarantine.

5. **`RejectArchiveModal.tsx`**:
   - Visual warehouse explorer and search engine for retained coarse rejects.
   - Filter by warehouse shed, rack, box, seal number, or parent drill hole.
   - Print reject bag QR tags.

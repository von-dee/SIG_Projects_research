# HGF End-to-End Fire Assay Workflow (13 Stages)

This document outlines the confirmed end-to-end assay workflow, stakeholder change requests, and audit requirements for the Heath Gold Fields (HGF) Prestea Mine LIMS prototype.

## Core Traceability & Tray Integrity Rules

To ensure strict audit compliance and physical sample tracking, the system enforces the following rules across the entire workflow:

* **Sample, Batch & Tray Tracking:** Every single transformation logs the specific **Sample ID** (e.g., `DDH-2214`), **Batch ID** (e.g., `B-700`), and **Tray/Container ID** (e.g., `Tray 4`).
* **Tray Dividing & Merging:** A single batch can be divided across multiple trays (e.g., at Drying due to the 81-sample tray limit). Conversely, multiple batches can be combined into a single tray (e.g., at Fusion if space allows). Samples from different batches on the same tray follow a strict, unbroken sequential line.
* **Tray Visualizer & Color Coding:** The LIMS UI features an interactive 9x9 grid (81 slots) representing the physical tray. Batch identity is indicated by the border color of the slot. Users can click any slot to view the specific Sample ID, Batch ID, and Tray Position.
  * 🟦 **Teal** = Batch B-700
  * 🟥 **Rust** = Batch B-701
  * 🟨 **Gold** = Current Tracked Sample (e.g., DDH-2214 at Pos 14)
  * ⬜ **Grey** = Empty Slot
* **Tray Integrity (Audit-Critical):** From Fusion to Cupellation, the exact tray and the sequential order of samples within that tray cannot be altered.

## 1. Field Sampling & Receiving

**Stage Type:** Input / Field & Receiving Clerk Station

**Detailed Step by Step:**

1. Capture drill hole, coordinates, and positioning at the rig.
2. Tie sample submission to borehole ID (Type HQ-2 / NQ-2).
3. Assign sample to primary Batch ID (e.g., B-700).
4. Auto-generate sample codes and print sticker/batch tags.
5. Sign off chain-of-custody for lab dispatch.
6. Verify manifest at receiving (flag mismatches).
7. Weigh sample using digital scale integration.
8. Accept, Hold, or Reject sample with mandatory reason codes.

**Tracking State:**

* *Note:* Sample enters the flow logged under Batch B-700.

## 2. Drying

**Stage Type:** Active Path

**Detailed Step by Step:**

1. Select the specific batch to process (B-700).
2. Divide large batches across multiple trays (B-700 split into Trays 1-4).
3. Select the specific samples/tray to load (max 81 samples per tray).
4. Place samples in Oven 1, 2, or 3.
5. Record drying start time and temperature setpoint.
6. Run cycle for a maximum of 8 hours.
7. Complete operator pre-transfer checklist before moving to the next stage.

## 4. Pulverizing

**Stage Type:** Active Path

**Detailed Step by Step:**

## 6. Fusion

**Stage Type:** Active Path

**Detailed Step by Step:**

1. Select Fusion Furnace 1 or 2.
2. Load the assay charge into a fusion tray.
3. Combine multiple batches into the same tray if space allows. *Tray contains multiple batches in strict sequential order (B-700 then B-701). Color-coded: Teal = B-700, Rust = B-701.*
4. Run fusion at ~1000°C to recover the lead button.
5. Weigh the resulting lead button to obtain the mass.
6. Discard slag (mass is logged for balance check).
7. Lock tray sequence and sequential order for cupellation (Audit-Critical).

6. Weigh the resulting prill on a microbalance.

6. Ensure client blind duplicates are reported as unknown samples.
7. Bring out all outliers for review.
8. Generate printable results and sign off.
9. Export report matching HGF shared field layout.

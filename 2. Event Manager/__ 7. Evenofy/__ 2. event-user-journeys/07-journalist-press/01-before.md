> Persona: Journalist / Press → Phase: Before the Event

## Before the Event

1. **Pitch and accreditation.** A journalist receives a story angle, applies with outlet evidence, and needs prompt confirmation. Touchpoints: press email, accreditation desk, editor. Risk: late approval makes travel impossible. Handoff: Media Centre.
2. **Planning.** They book travel, request interviews, and build a deadline diary from embargoed advisories. Delight: a credible, usable media brief. Handoff: PR Team.
3. **48-hour countdown.** Access rules, press-room location, spokesperson list, and briefing times arrive. Handoff: Media Desk.

> Persona: Virtual / Remote Attendee → Phase: Before the Event

1. **Discovery.** They see a digital programme and assess whether remote access is substantive. Handoff: Digital Marketing.
2. **Registration and setup.** They register, select time-zone-aware sessions, test access, and set reminders. Risk: unclear platform instructions leave them excluded. Handoff: Virtual Support.
3. **48-hour welcome.** Personal schedule, access check, and live support route arrive. Delight: a remote networking introduction. Handoff: Digital Experience.

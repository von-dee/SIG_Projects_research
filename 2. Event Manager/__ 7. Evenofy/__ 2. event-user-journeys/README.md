# Event User Journeys

## Personas

1. VIP / Head of State or Minister
2. Government Delegate
3. Investor / Corporate Executive
4. Speaker / Panelist
5. Sponsor Representative
6. Exhibitor / Booth Staff
7. Journalist / Press
8. General Attendee
9. Student / Academic Attendee
10. Volunteer / Front-line Staff
11. Event Operations / War Room Staff
12. Virtual / Remote Attendee
13. Driver / Chauffeur, added because arrival, motorcade timing, and secure handoffs otherwise have no accountable human journey.

Every persona folder contains `01-before.md`, `02-during.md`, and `03-after.md`. See `00-overview/00-persona-summary.md` and `00-overview/01-journey-map-legend.md` before reading an individual path.

> Module 1: Admin Command Center → Global Dashboard → Venue Heatmap

## Venue Heatmap
**Purpose & users:** Ops, Security, and Event Directors monitor crowd concentration and flow.

**Features:** layered campus map; room/zone occupancy color scale; live check-in counts; capacity threshold indicators; time scrubber; ingress/egress trend; manual observation input; zone drill-down; alternate-route notice action.

**Workflow:** Select event day and map layer → inspect red/amber zones → open zone detail to confirm recent scans and capacity → dispatch volunteer or publish rerouting message → record resolution.

**States & guardrails:** distinguish live, delayed, and manual counts. When scanner data fails, retain last known value with timestamp and do not imply live occupancy. Restricted zones are hidden from unauthorized roles.

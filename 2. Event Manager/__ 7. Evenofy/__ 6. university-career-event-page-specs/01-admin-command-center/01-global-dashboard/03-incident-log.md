> Module 1: Admin Command Center → Global Dashboard → Incident Log

## Incident Log
**Purpose & users:** Gives designated operations leaders a prioritized feed of event-day issues.

**Features:** severity and status filters; incident timeline; reporter, zone, media, notes, assignment, SLA timer, related incidents, escalation action, and closure summary; private medical/security handling.

**Workflow:** Open new alert → validate severity → assign accountable responder → communicate next action → add updates and evidence → escalate or resolve → record outcome and lessons.

**States & guardrails:** duplicates can be linked; only authorized leads can change critical severity or access sensitive reports. The reporter receives acknowledgement, and a closed incident requires a resolution note.

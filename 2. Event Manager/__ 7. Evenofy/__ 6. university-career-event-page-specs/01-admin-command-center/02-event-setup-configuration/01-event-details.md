> Module 1: Admin Command Center → Event Setup & Configuration → Event Details

## Event Details
**Purpose & users:** Event Administrators establish the official event identity and operating context.

**Features:** event name, short name, dates/times, time zone, venue addresses, public description, contacts, branding assets, campus-map upload, registration window, and status controls.

**Workflow:** Create draft event → enter core details → upload/validate map and brand assets → save preview → route for Director approval → publish configuration for downstream teams.

**States & guardrails:** validate date order, time zone, address completeness, image formats, and collision with existing published events. Published dates or venue changes prompt an impact notice to Registration, Agenda, and Logistics.

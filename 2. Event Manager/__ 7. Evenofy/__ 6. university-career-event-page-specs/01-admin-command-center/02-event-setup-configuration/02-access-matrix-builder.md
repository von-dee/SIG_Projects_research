## Access Matrix Builder
**Purpose & users:** Security and Registration define what each participant group may enter or use.

**Features:** participant roles, access zones, valid dates/times, escort requirement, badge template mapping, matrix grid, bulk rule copy, conflict validator, simulation view, approval history.

**Workflow:** Create role such as Employer, Senior, Freshman, or Volunteer → select allowed zones and schedule → test sample credential decisions → submit for Security approval → activate before badges are issued.

**States & guardrails:** prevent an active role with no access or conflicting rules. Changes after badges are printed display affected counts and require an authorized exception; every change is auditable.

## Master Timeline
**Purpose & users:** Content, Production, and Ops coordinate the event's minute-by-minute execution.

**Features:** Gantt timeline by stage/room; sessions, setup, changeover, arrivals, meal breaks, dependencies, owners, status, filters, conflict warnings, version comparison, and printable daily view.

**Workflow:** Add or import agenda items → set duration, location, and owner → link prerequisite cues → resolve overlaps → submit a version for approval → publish a read-only operational run sheet.

**States & guardrails:** prevent simultaneous use of one room or speaker; warn on impossible turnaround. Live-day edits create a new revision and notify only affected teams.

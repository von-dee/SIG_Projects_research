## Cue Sheet Generator
**Purpose & users:** AV, lighting, stage managers, and presenters receive an executable cue plan.

**Features:** cue type, timecode, owner, asset link, notes, confirmation checkbox, stage filter, print/PDF layout, revision label, and distribution list.

**Workflow:** Select a timeline/session → add or import AV, lighting, video, and walk-on cues → sequence and validate times → request technical confirmation → generate current cue sheet → distribute to approved teams.

**States & guardrails:** unconfirmed or missing assets are prominent; generated sheets identify version and print time. After production lock, changes require Stage Manager approval.

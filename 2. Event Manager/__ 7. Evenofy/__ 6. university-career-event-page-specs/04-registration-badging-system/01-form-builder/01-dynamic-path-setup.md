> Module 4: Registration & Badging System → Form Builder → Dynamic Path Setup

## Dynamic Path Setup
**Purpose & users:** Registration Administrators tailor application journeys to participant type.

**Features:** path builder; eligibility conditions; .edu-domain/classification rules; steps; question sets; approvals; payment; confirmation messages; preview; versioning; activation window.

**Workflow:** Select participant audience → assemble steps and conditions → preview test identities → route for compliance review → publish for a date range → monitor completion and exceptions.

**States & guardrails:** block impossible condition loops and inaccessible required fields. Active paths are versioned; in-progress registrants keep a consistent path unless an administrator communicates a controlled change.

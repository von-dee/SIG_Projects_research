> Module 4: Registration & Badging System → Badge & Check-In → Door Scanner Dashboard

## Door Scanner Dashboard
**Purpose & users:** Registration, Security, and Ops observe entrance health and room capacity.

**Features:** reader list; online/offline status; allow/deny counts; throughput; occupancy; threshold alerts; last scan; device diagnostics; manual capacity adjustment; incident shortcut.

**Workflow:** Monitor active doors → investigate a degraded reader or rising denial rate → dispatch support or activate backup lane → set controlled capacity action → document restored service.

**States & guardrails:** duplicate scans do not inflate occupancy. Only security-approved users adjust capacity; offline readers show snapshot age and sync buffered events when restored.

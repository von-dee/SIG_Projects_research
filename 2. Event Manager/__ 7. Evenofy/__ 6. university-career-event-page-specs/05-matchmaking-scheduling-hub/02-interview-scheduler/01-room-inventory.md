> Module 5: Matchmaking & Scheduling Hub → Interview Scheduler → Room Inventory

## Room Inventory
**Purpose & users:** Career Services and Facilities define interview spaces and their availability.

**Features:** room list/map; capacity; accessibility; equipment; privacy level; available intervals; maintenance block; employer allocation; booking status; issue reporting.

**Workflow:** Import approved rooms → set features and time windows → reserve blocks for employers or inclusive access → release remaining slots → adjust status during event → resolve room issue and reassign bookings.

**States & guardrails:** unavailable rooms cannot be booked. A room move identifies all impacted interviews and requires notification before confirmation.

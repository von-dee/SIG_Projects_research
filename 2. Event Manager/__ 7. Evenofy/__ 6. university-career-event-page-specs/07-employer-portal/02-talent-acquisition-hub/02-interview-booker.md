> Module 7: Employer Portal → Talent Acquisition Hub → Interview Booker

## Interview Booker
**Purpose & users:** Recruiters request and manage concise, respectful student interviews.

**Features:** candidate selector; available slots; room options; invitation template; interviewer roster; waitlist; reschedule/cancel; calendar status; check-in; feedback note.

**Workflow:** Choose student → view compatible availability → select 15-minute slot and room → send request → student accepts/declines → confirm attendees → check in and capture follow-up note.

**States & guardrails:** no booking can override student class or confirmed event commitment. Repeated reschedules are flagged; employers cannot see private student calendar details.

> Module 8: Student Portal → Student Dashboard → Personalized Agenda

## Personalized Agenda
**Purpose & users:** Students plan a realistic, valuable event day.

**Features:** session and employer browse; map; filters; save/add; time conflict warning; interview integration; travel-time guidance; reminders; accessibility and virtual labels; printable/mobile schedule.

**Workflow:** Browse sessions, booths, and activities → filter by career goal → add preferred items → resolve conflicts → receive reminders and live room changes → check off attended items.

**States & guardrails:** show full/cancelled/moved sessions immediately. A saved item does not guarantee seat unless it is ticketed; offline mode retains the last synchronized agenda.

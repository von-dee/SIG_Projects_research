Why This Exists

The earth talks. We just never had one window to hear it all.

Mining permits, vessel transponders, rail telemetry, seismic stations, satellite fire detections, commodity exchange feeds, ESG disclosures, and regulatory filings already tell us a great deal about the planet's resource heartbeat. God's Eye View fuses them into a single, inspectable globe — for analysts, geologists, journalists, students, and the plain curious.

⛏️

From ore body to export

Track a commodity from the deposit, through the mill, onto the rail car, into the port, onto the bulker — all on one globe. Each step is a layer you can toggle, interrogate, and extend.

🛰️

Public signals, real sources

Every layer traces back to a named, documented source — USGS, OpenSky, AISStream, CelesTrak, NASA FIRMS, UN Comtrade, ICMM, SEDAR+. No mystery scraping. No private datasets.

🔓

Local-first, inspectable

Runs in your browser. The code is yours to read, fork, and bend. Half the magic is the forbidden-cockpit aesthetic — the other half is that every line is auditable.

Capabilities

A console for the resource planet.

Fifteen live layers. Sensor-grade visualization. A voice agent that knows what it's looking at. And a cockpit mode that lets you ride any tracked contact — be it a haul truck, a drill rig, an ore train, or a Capesize bulker.

CORE
⛏️

Mine-Site Cockpit View

Ride inside any tracked asset — a haul truck on the pit floor, a dragline swing, a drill rig pattern, a longwall shearer. The camera holds the terrain underneath you all the way down, with sensor modes coming along for the ride.

CORE
📡

Contact Roster (250 km)

A live roster of everything near your target — vessels in port, ore trains on the network, helicopters servicing rigs, seismic events, satellite passes. Step through contacts and drop into any cockpit with a click.

LOCK-ON

🎯 Click-to-Track Anything

Camera locks on, draws a fading trail, surfaces full metadata. A tracked vessel hands off to the nearest port camera; a tracked fire hands off to the nearest public webcam.

ANNOTATE

🖊️ Voice Whiteboard

Speak annotations onto the world — real boundary polygons, marks, and routes drawn over concessions, tenements, and claim blocks.

3D

🚂 Asset Hangar

Real per-class 3D models — haul trucks, excavators, draglines, locomotives, bulkers, drillships — swap from glyph to model as you close in.

SENSOR STACK

🎨 Reskin Reality (1–7)

GLSL sensor shaders over the normal globe — 1 CRT, 2 NVG, 3 FLIR/thermal, 4 Ironbow, 5 Noir, 6 Snow, 7 Hyperspectral-pseudo.

DETECTION

🟩 Detection Overlay

Screen-space bounding boxes and IDs on every tracked contact in view — vessels, aircraft, trucks, trains, fires — with confidence and class.

HUD

🎖️ Tactical HUD

Intelligence-style heads-up display with telemetry: heading, speed, altitude/depth, commodity, destination, ETA.

CONTEXT

🌐 Global ↔ Local

Stage the full situational picture with one switch — and get your exact view back when you leave.

SHARE

🔗 Serialized Links

Camera, style, layers, and one tracked target serialize into a URL. A live contact is a handoff, not a bookmark.

DIRECTOR

🎥 Scene Director

Capture cinematic camera tours for briefings, reports, and documentaries. Frame shots, sequence them, playback at 0.25×–4×.

RESET

🏠 One-Click Globe Reset

One control — or one sentence — back to the full Earth. Lose yourself in the detail; find your way home in a breath.

Quick Start

Start without API keys.

Both paths open the same app with Esri satellite imagery and keyless terrain. OSM is the fallback if Esri is unreachable. Mineral deposits, tailings dams, earthquakes, public cameras, radio, and launches are available without keys.

EASIEST

Path 1 — One click, no terminal

Install or update Pinokio to 8.2 or later.
  1. Install Pinokio from the official website.
  2. Open God's Eye View in Pinokio.
  3. Click Install, then Start.
  4. Choose a first-run mission — or explore manually.

Available on Windows, macOS, and Linux. The launcher installs locked dependencies, finds a free local port, and opens the app.

Path 2 — Terminal / coding agent

Node.js 24.x (24.14.0+) or 26.x. Setup doctor warns about Node 25 (EOL).
# Clone & install
git clone https://github.com/bilawalsidhu/gods-eye-view.git
cd gods-eye-view
npm ci
npm run doctor
npm run dev

# Open
→ http://localhost:4173

Drop the GitHub link into Claude Code, Cursor, or any AI coding agent for hands-off setup. macOS shortcut: ./scripts/dev-fresh.sh clears the Vite cache and pulls configured keys from Keychain.

Talk to the Planet

Voice needs an OpenAI key. Without one, the rest still runs.

The mic button reports unavailable without a key. The same key drives the AI HUD summary: a terse, five-word intelligence-style readout of the current view that regenerates as you move.

"Take me to Escondida and orbit the pit."
→ Flying to Escondida copper mine, Chile. Slow orbit engaged.
"What's the production here?"
→ Escondida is the world's largest copper producer by output, ~1 Mt Cu/yr, operated by BHP. Porphyry copper deposit.

Field Missions

Once the basics click, run these.

Real workflows geologists, journalists, analysts, and commodity traders use to interrogate the planet.

🚢
Port call — Pilbara

Vessels on over Port Hedland. Click a bulker for its tactical card and wake trail — then hit NEAREST in the CCTV panel and look at the same water through a public camera.

🔥
Coal-seam fire line

FIRMS over Jharia or Centralia. Click a detection — the camera dives to it — read the intensity, then hit NEAREST in the CCTV panel for a ground view.

🏗️
Orbit Brumadinho

Sweep the failed dam footprint and its terrain at a glance — then flip on the Tailings Dams layer and find 703 more.

🌍
Seismic watch

Earthquakes on over the Andes or Tonga trench. Click an event — see magnitude, depth, affected mines within 250 km. Critical for tailings-stability review.

🎙️
Ask the planet VOICE

"Why are all these bulkers queued off Singapore?" Select a vessel — it silently backfills ~24 h of trace history — and see what it's been doing, resolved as stacked 3D loops.

🎙️
Walk a route VOICE

"Draw the rail route from Carajás to São Luís." A real street-following route traces itself through the 3D terrain — then "fly it": banked turns, eased ends, a camera that leads like a drone shot.

📏
Measure pit-to-port VOICE

"How far is Bingham Canyon from the Port of Salt Lake?" — an arrow spans the distance, the length lands in the caption, endpoints stay pinned to the real world as you orbit.

🚀
Launch replay

Open Space Missions, pick an EO satellite launch from the last 30 days, and ride the T-minus countdown through ascent to orbit — scrub it at 0.25×–4×. Labeled RECONSTRUCTED ESTIMATE, because it is one.

🪦
Walk the boneyard

Fly from regional context down into dense, fully resolved rows of retired aircraft at Davis-Monthan or Victorville — fully resolved in 3D.

🏗️
Orbit Three Gorges

Sweep the dam and its terrain at a glance — then flip on the Dams layer and find 703 more. Hydroelectric capacity overlaid on the 3D basin.

🛰️
Track Sentinel-2

Turn on Satellites and click Sentinel-2A — ride along at orbital distance. Critical for understanding revisit cadence over your mine sites.

🏭
Smelter watch

Turn on Smelters & Refineries. Hover any facility for capacity, feed type, and operator. Cross-reference with vessels nearby to infer throughput.

Under the Hood

Built to be read, not just run.

How the globe handles live data — and stays honest doing it.

01
World-stable icons

Aircraft, ships, and haul trucks point along their true real-world heading at every camera angle — tracked or not, looking straight down or across the horizon — via per-frame screen-space course projection. No spinning, no viewport-locking.

02
Smooth motion from choppy data

Live feeds arrive every 15–30s; the globe renders one interval behind real time and interpolates between known fixes. Dead reckoning fills the gaps.

03
Honest satellites

SGP4 propagation with orbit rings that stay locked to their satellites via GMST realignment — no drift, no per-second flicker.

04
Sits on the real ground

Entity heights are aligned to work with Google 3D tiles, so aircraft park on aprons, trucks sit on haul roads, and cameras stand on street corners instead of floating.

05
Caching & request budgets

An OpenSky credit governor, a TomTom daily tile budget, and disk-cached TLEs reduce repeated requests. These controls do not replace provider quotas or billing controls.

06
Server-side credentials

Every API that touches a private key (OpenAI, AISStream, OpenSky OAuth, camera frames) is brokered through a hardened server-side proxy with SSRF protection, response caps, and sanitized errors.

07
No framework

Vanilla JavaScript, CesiumJS, and Vite — plus Google Photorealistic 3D Tiles for the planet and the OpenAI Realtime API for voice. Fast to read, fast to hack on.

🧗

The floor is low on purpose. The ceiling: terrestrial AIS goes quiet mid-ocean and satellite AIS costs real money; premium imagery, SAR, and the deeper commercial feeds live behind enterprise contracts. That's not a limit of the architecture — every layer here is a pattern you can point at your own data sources.

⚠️

Sharing an instance: By default nobody else can reach your server — it binds to localhost. To share on your LAN, opt in explicitly. A LAN-visible server brokers your configured API keys to anyone who can reach it. Configure provider quotas, usage limits, and billing alerts. Full threat model in SECURITY.md.

Responsible & Open

A canvas, not a product.

God's Eye View runs on public data, clear sources, and local-first execution. No secrets, no private datasets, no mystery scraping. It has the visual grammar of a classified ops room, built entirely from open signals and inspectable code.

THE LINE

People are not a query type here.

This project models events, assets, infrastructure, and systems — mines, vessels, satellites, fires, cameras, cities. It does not build features for named-person search, face recognition, or tracking individuals. Pull requests that cross that line won't be merged.

CANVAS

Come build it.

Add a mine pack, a data source, a style, a voice tool. The layers here are the signals one person could find and fuse. It's the window through which you see the world; bring that window to others.

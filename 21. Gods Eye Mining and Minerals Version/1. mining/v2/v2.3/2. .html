How to Add & Upload Your Data Sources

God's Eye View is an open canvas. Bring your own feeds, shapefiles, or real-time APIs to power the use cases below. Choose the method that fits your data type.

📂
Upload Static Data (GeoJSON/CSV)
  1. Create a folder in src/data/local_data/your_dataset/
  2. Drop your data.geojson file and a README.md for provenance.
  3. Create a layer module in src/data/yourLayer.js that fetches and renders it.
fetch('./data/local_data/your_dataset/data.geojson')
📡
Connect Live API Feeds
  1. Define the layer in src/data/yourLayer.js following the anatomy contract.
  2. Implement the refresh() method to fetch JSON from your API.
  3. Register the layer in src/main.js. It auto-appears in the UI.
async refresh() { await fetch('https://api.yoursource.com') }
🔑
Secure Private API Keys
  1. Click the POWER UP chip in the bottom right corner of the app.
  2. Paste provider keys (Cesium, Google, AISStream, etc.) and hit Save.
  3. For custom private APIs, add a server-side proxy route to keep keys off the client.
SERVER PROXY: ssrfGuard(url); cappedFetch(target);
🤖
AI-Assisted Layer Creation
  1. Clone the repo and open it in Cursor, Claude Code, or Codex.
  2. The vanilla JS architecture is agent-friendly—no framework magic.
  3. Prompt: "Create a GEV layer for [My Data] that plots [Points] and updates every [X] seconds."

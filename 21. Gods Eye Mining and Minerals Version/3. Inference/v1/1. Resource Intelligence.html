§ 05

Methodology Legend

01 Static

Bundle a file

A pre-downloaded dataset bundled into local_data/. Lowest latency, no API key, full reproducibility. Updated quarterly.

02 Live

Poll a public API

A no-key, no-cost endpoint polled directly from the browser. Subject to rate limits and CORS. Best for low-frequency data like earthquakes, weather, and trade flows.

03 Keyed

Broker through server

A keyed or paid API brokered through the server's POWER UP panel. Keys never reach the client. Response caps prevent runaway bills.

✅ Integrated

Shipped in build

Already live in the current production build. Polling, rendering, and UI affordances are wired end-to-end.

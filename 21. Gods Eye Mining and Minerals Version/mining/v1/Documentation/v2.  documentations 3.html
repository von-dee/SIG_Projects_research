MOTHERLODE

A mineral reconnaissance satellite in your browser — the deposits are real, the data is public. This manual documents every panel, layer, command, tour and record in the console. Keyless. Offline. One file.

ML-01OVERVIEW

What MOTHERLODE is, and the philosophy behind it.

MOTHERLODE puts the world's mineral intelligence into one explorable console: 122 real mines across 18 commodities, 11 tailings facility records with consequence ratings, 7 processing plants, a simulated commodity wire, incident feed and seismicity monitor — all rendered on a stylized vector globe you can spin, zoom and interrogate.

It borrows the visual grammar of a classified ops room and builds it entirely from open, public signals. No accounts, no API keys, no network calls. Everything runs inside one HTML file on your machine.

THE FOUR THINGS IT DOES

  • Survey — light up commodity layers on the globe, from copper kingdoms to the Lithium Triangle, and see production, operator and assay data for each contact.
  • Track — click any mine, dam or smelter. The camera locks on, draws assay rings, and raises a live telemetry card.
  • Dive — enter Pit Mode: modeled open pits with haul ramps and trucks, underground shaft sections, brine pond grids, tailings cross-sections.
  • Command — a local console parser: type "track grasberg", "show lithium", "nvg", "tour copper". No microphone, no key, no cloud.
THE LINE MOTHERLODE models sites, infrastructure and public data. It does not build features for named-person search or tracking individuals. People are not a query type here.

ML-02QUICK START

From zero to a live globe in one step.

  1. Open index.html in any modern browser (Chrome, Edge, Firefox, Safari). No server, no build step, no install.
  2. Watch the boot sequence (~4 seconds) — it mounts the local data stores and arms the simulated feeds.
  3. Pick a first-run mission from the cards, or press ENTER NOW to go straight in with everything on.
KEYLESS BOOT 0 keys · 0 accounts · 100% local. The POWER UP button opens the sources panel out of tradition — in this build there is nothing to power up. In a full deployment, live feeds (USGS MRDS, Mindat, Global Tailings Portal, broker wires) would bolt onto the same layer pattern.

ML-10PIT MODE

The cockpit view of the mining world — five modeled scene types, one per contact kind. Enter with P, the card button, or pit. Exit with Esc.

OPEN PIT (▲)

Nine terraced benches tinted by commodity, a spiral haul ramp, three animated trucks cycling rim-to-floor, bench depth labels (site-specific: Bingham −1,200 m, Chuquicamata −1,050 m…), equipment on the pit floor. Closed sites render rust-toned with a water pool and a CARE & MAINTENANCE banner.

UNDERGROUND (●)

Headframe with sheave wheel, animated cage in the shaft, six levels with drifts and blinking stopes, vent raises, orepass to a bottom crusher. Depth labels are site-specific — Mponeng runs to −4,000 m, "deepest mine on Earth."

BRINE PONDS (◆)

A staged evaporation pond grid — five colors from dilute feed to concentrated brine, shimmering water, salt crusts on late stages, pump station and pipeline. Rendered for Atacama, Hombre Muerto, Olaroz.

TAILINGS CROSS-SECTION (■)

Staged embankment raises, the pond, a decant tower, and a blinking piezometer. Status banner per record — failed dams show a release-footprint note instead of water. For the 11 TSF records (ML-19).

SITE PLAN (◎ / △ DEV)

For plants and developments: process buildings with beacon-lit stacks, conveyors, stockpiles, haul road, a dashed future-pit outline, and blinking survey markers. Banners read PROCESSING / DEVELOPMENT SITE PLAN.

ALWAYS LABELED Every pit scene carries the strip: GEOMETRY MODELED FOR ILLUSTRATION — SITE POSITIONS & ASSAY DATA FROM PUBLIC SOURCES. The pit views are drawings, not surveys. Mouse movement adds gentle parallax; the scene re-skins with the active sensor style.

ML-11SENSOR STACK

Seven optics presets — keys 1–7. Each recolors the globe, the markers and the whole UI chrome via CSS variables.

TACTICAL KEY 1

The default. Dark ops-room palette, full commodity colors, green atmosphere limb.

CRT KEY 2

Green phosphor monochrome with heavy scanlines. Every marker renders in one green.

NVG KEY 3

Night vision gain — bright land masses, glowing coastlines, lighter scanlines.

FLIR IRONBOW KEY 4

Thermal palette. Tier-1 sites render hot white-yellow, tier-2 cool red — the majors glow.

FLIR WHITE-HOT KEY 5

Grayscale thermal. Land bright, ocean black, high-contrast limb.

NOIR KEY 6

Hard monochrome, white markers, near-invisible scanlines.

SPECTRAL KEY 7

False-color "geology" mode — every landmass polygon gets its own hue, as if classified by hyperspectral band.

Console: nvg, crt, flir, noir, spectral, style spectral, or a bare digit 4.

ML-12DETECTION MESH

The object-detection overlay — D or detect on.

Every visible contact gets screen-space corner brackets and a tag: CU-001 ▓ 95% — site code plus a stable pseudo-confidence derived from the site ID hash (92–99%, deterministic so it doesn't flicker).

  • Capped at the 36 contacts nearest your view center — the "mesh" reads clean at any zoom.
  • Boxes and tags render in the active palette's accent color.
  • Combine with zoom + labels off for a pure machine-vision look; combine with NVG for night-watch operations.

ML-16COMMODITY TICKER

Sixteen instruments, bottom strip, scrolling continuously. Hover to freeze.

Each instrument random-walks ±0.35% every 2.6 s around a plausible base level; change % flashes green/red on update. Values appear in the console via price gold. Indicative and simulated — never a quote.

ML-17SEISMICITY

Modeled mining-induced events — cyan expanding rings, ML 1.5–3.4.

  • Events spawn every ~9–15 s (80% probability while the layer is on), positioned within ~±0.6° of monitored deep mines: Mponeng, El Teniente, Norilsk, Sudbury, Chuquicamata, Kamoá-Kakula, Oyu Tolgoi.
  • Each event renders as two expanding rings over ~5 s with an ML 2.3 tag, then expires. A rolling window of ~7 events.
  • Seed four events at boot so the globe is alive immediately.
  • Console: seismic forces one. Toggle the layer in the panel or console.

Clearly labeled SIM — these are demonstrations of event visualization, not real networks.

ML-21UNDER THE HOOD

How a 3,000-line single file does all of this. No framework, no build step, no dependencies.

THE GLOBE MATH

An orthographic projection with two camera angles — yaw (spin) and tilt — plus zoom. Every frame, each lat/lng becomes a 3D unit vector, rotates through the camera, and projects to screen:

// spherical → rotated → screen (behind-globe returns null)
la = lat·D2R; lo = lng·D2R + cam.yaw
x = cos(la)·sin(lo)   y = sin(la)   z = cos(la)·cos(lo)
y' = y·cos(tilt) − z·sin(tilt)      z' = y·sin(tilt) + z·cos(tilt)
if z' ≤ 0.015 → null
screen = (W/2 + x·R,  H/2 − y'·R)          // R = globe radius = min(W,H)·0.42·zoom

Land masses are hand-simplified coastline polygons filled inside a canvas clip of the globe disc; the graticule is 15° meridians/parallels drawn as segmented polylines that break at the horizon.

CAMERA & MOTION

  • Fly-to tweens — every jump is a cubic ease-in-out over yaw (shortest angular path), tilt and zoom simultaneously; tours chain them.
  • Inertia — drag velocity decays ×0.93 per frame after release.
  • Auto-spin engages after 4 s idle, suppressed while tracking or touring.

PERFORMANCE & ROBUSTNESS

  • One requestAnimationFrame loop that reschedules itself before drawing — a single throwing frame can never freeze the console.
  • DOM updates throttled to 4 Hz; the roster rebuilds only when the camera moves meaningfully.
  • Marker LOD by tier (ML-05); label ceiling of 72; detection ceiling of 36.
  • shadowBlur reserved for tier-1 markers, the limb and the reticle — the expensive canvas effects stay scarce on purpose.
  • Global window.onerror trap prints any runtime error into the console panel — failures are never silent.

THE SIMULATORS

  • Prices — per-instrument multiplicative random walk every 2.6 s.
  • Wire — seven template families drawing from the site registry every 8 s.
  • Seismicity — proximity-weighted spawns near deep mines.
  • Telemetry — ore tonnage, energy and fleet counters random-walk per second on the tracked card.

GO FURTHER

  • Live feeds — the layer panel toggles and the draw loop are the integration surface for USGS MRDS queries, Mindat lookups, or a broker wire. Each layer is an independent module.
  • Real 3D — swap the canvas globe for CesiumJS with an ion token; every site already carries lat/lng/height-ready fields.
  • More pit variants — drawOpenPit / drawUnderground / drawBrinePonds / drawTSFPit / drawSitePlan are self-contained scene painters keyed off site.type.
  • Alert templates — add branches to genAlert(); anything with a site reference becomes clickable-to-fly automatically.

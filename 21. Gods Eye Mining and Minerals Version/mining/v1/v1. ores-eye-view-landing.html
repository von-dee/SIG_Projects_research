Ride the supply chain, not a spreadsheet.

Every layer here is something you can click into, follow, and ask questions of — not a static report.

Featured mode

Pit Cab

Drop into a tracked haul truck and ride it down the bench, real terrain holding underneath the whole way. Switch sensors mid-descent — Satellite into Ore-Grade Thermal — and jump straight to the next truck without leaving the cab.

Tracking

Click-to-track anything

Lock onto a bulk carrier, a mine, or a haul truck. The camera follows, a trail draws behind it, and full metadata surfaces — one click hands you off to the nearest site camera.

Optics

Reskin reality

Five sensor looks over the same live globe: Satellite, Geological, Ore-Grade Thermal, Night, Seismic. The whole planet re-renders through a different lens.

Voice

Talk to the deposit map

"Which mines are producing cobalt today?" A realtime agent pulls live scene context and answers from what's actually on screen.

Annotation

Draw on the real world

Outline a tenement, measure pit to port, sketch a haul route — by voice or by hand. Everything persists until you clear the map.

quick start

Start without an account or API keys

Both paths open the same app with keyless satellite imagery and terrain. Mines, deposits, bulk carriers, seismic activity and commodity prices all work with nothing configured.

One click, no terminal

Windows · macOS · Linux, via Pinokio

  1. Install or update Pinokio to 8.2 or later.
  2. Open Ore's Eye View in Pinokio.
  3. Click Install, then Start.

Terminal / coding agent

Node.js 24.x (24.14.0+) or 26.x

git clone https://github.com/example/ores-eye-view.git
cd ores-eye-view
npm ci
npm run dev
voice

Talk to it

Needs an OpenAI key — without one the console still runs, the mic just goes quiet. The agent pulls live scene context before it answers.

Direct it
"Take me to the Atacama."
"Draw the haul route from the crusher to the stockpile — now fly it."
Interrogate it
"How many bulk carriers are headed to Rotterdam right now?"
"Which mines are producing cobalt today?"
Annotate it
"Outline this tenement."
"How far is the mine from the nearest port?"
Operate it
"Switch to ore-grade thermal and turn on the deposits layer."
"Track that carrier." → "Enter Pit Cab."

Responsible & open. Ore's Eye View runs on public data, clear sources, and local-first execution — anything involving a private key is brokered server-side. Data may be delayed, incomplete, modeled, or wrong; this is an exploratory visualization, not a tool for investment, operational, safety-critical, or navigational decisions. Verify anything that matters against authoritative sources.

Why This Exists

The earth talks. We just never had one window to hear it all.

Mining permits, vessel transponders, rail telemetry, seismic stations, satellite fire detections, commodity exchange feeds, ESG disclosures, and regulatory filings already tell us a great deal about the planet's resource heartbeat. God's Eye View fuses them into a single, inspectable globe.

⛏️

From ore body to export

Track a commodity from the deposit, through the mill, onto the rail car, into the port, onto the bulker — all on one globe. Each step is a layer you can toggle, interrogate, and extend.

🛰️

Public signals, real sources

Every layer traces back to a named, documented source — USGS, OpenSky, AISStream, CelesTrak, NASA FIRMS, UN Comtrade, ICMM, SEDAR+. No mystery scraping. No private datasets.

🔓

Local-first, inspectable

Runs in your browser. The code is yours to read, fork, and bend. Half the magic is the forbidden-cockpit aesthetic — the other half is that every line is auditable.

Upload Guide

How to Add & Upload Every Data Source

God's Eye View uses a module-per-layer architecture. Every source above can be integrated via one of four methods. Below is a per-source guide for all 100+ sources — format, method, file path, and integration code.

📂
METHOD 01

Bundled Static Data

Drop a GeoJSON/CSV/JSON into src/data/local_data/. Loaded at init. Best for catalogs & inventories.

src/data/local_data/your_set/data.geojson
📡
METHOD 02

Live API Polling

Write a refresh() method fetching JSON from a public API. Best for keyless feeds.

async refresh() { fetch(url) }
🔑
METHOD 03

Keyed API via POWER UP

Declare provider in keySetup.js, paste key in POWER UP panel, broker through server proxy with SSRF.

server/routes/yourkey.js → ssrfGuard()
🤖
METHOD 04

AI-Assisted Integration

Clone into Cursor/Claude Code/Codex. Describe the layer in natural language. Vanilla JS is agent-friendly.

"Create a GEV layer for [source]..."
📐

Every layer follows the same contract: id, name, init(), enable(), disable(), update(), refresh(), onTrack(). Register in src/main.js — the UI picks it up automatically.

Quick Start

Start without API keys.

Both paths open the same app with Esri satellite imagery and keyless terrain. Mineral deposits, tailings, earthquakes, cameras, radio, and launches are available without keys.

EASIEST

Path 1 — One click, no terminal

Install Pinokio 8.2+ on Windows, macOS, or Linux.
  1. Install Pinokio from the official website.
  2. Open God's Eye View in Pinokio.
  3. Click Install, then Start.
  4. Choose a first-run mission — or explore manually.

Node.js 24.x (24.14.0+) or 26.x.
# Clone & install
git clone https://github.com/bilawalsidhu/gods-eye-view.git
cd gods-eye-view
npm ci
npm run doctor
npm run dev

# Open
→ http://localhost:4173

Drop the GitHub link into Cursor, Claude Code, or any AI coding agent. macOS: ./scripts/dev-fresh.sh clears cache & pulls keys from Keychain.

Under the Hood

Built to be read, not just run.

01
World-stable icons

Aircraft, ships, and haul trucks point along true heading at every camera angle via per-frame screen-space projection.

02
Smooth motion from choppy data

Live feeds arrive every 15–30s; the globe renders one interval behind real time and interpolates. Dead reckoning fills gaps.

03
Honest satellites

SGP4 propagation with orbit rings locked via GMST realignment — no drift, no per-second flicker.

04
Sits on the real ground

Entity heights aligned to work with Google 3D tiles — trucks on haul roads, cameras on street corners.

05
Caching & request budgets

OpenSky credit governor, TomTom daily tile budget, disk-cached TLEs. Controls do not replace provider quotas.

06
Server-side credentials

Every private key brokered through a hardened server-side proxy with SSRF protection, response caps, sanitized errors.

07
No framework

Vanilla JavaScript, CesiumJS, Vite — plus Google 3D Tiles and OpenAI Realtime API. Fast to read, fast to hack.

Responsible & Open

A canvas, not a product.

God's Eye View runs on public data, clear sources, and local-first execution. No secrets, no private datasets, no mystery scraping.

THE LINE

People are not a query type here.

This project models events, assets, infrastructure, and systems — mines, vessels, satellites, fires, cameras, cities. It does not build features for named-person search, face recognition, or tracking individuals.

CANVAS

⚠️

Important: God's Eye View is an exploratory visualization of public and third-party data. Data may be delayed, incomplete, modeled, inferred, or wrong. Do not use it for mining operations, tailings-stability decisions, environmental compliance, navigation, or emergency response. Verify important information with authoritative sources.

Confidence Framework

How to trust a fused signal.

Not every inference is equally reliable. The framework below helps clients calibrate how much capital or decision weight to place on each signal. Three sources agreeing = a trade. Five sources agreeing = a strategic decision.

HIGH CONFIDENCE

80–100%

Multiple independent sources agree. Signal is measurable, verifiable, and has been backtested against historical events. Safe for capital allocation.

  • Supply disruption (vessels + lights + rail = 0)
  • Mine closure/reopening (4+ source delta)
  • Trade flow diversion (AIS + port calls confirm)
  • Production estimation (3+ sources triangulate)

MEDIUM CONFIDENCE

55–79%

2–3 sources agree but one or more have latency, resolution limits, or alternative explanations. Use for screening and hypothesis formation, not bare capital allocation.

  • Tailings risk (no single factor predicts failure)
  • Smelter utilization (night lights are coarse)
  • Exploration detection (could be private drilling)
  • M&A prediction (many false positives)

LOW CONFIDENCE

<55%

Single-source or highly interpretive signals. Useful as early-warning hypotheses that require human verification before any action. Never trade on these alone.

  • Single satellite image interpretation
  • One vessel going dark (could be technical)
  • Stock options flow without physical confirmation
  • Any signal with <3 source agreement
⚠️

Critical rule: No inference — no matter how many sources agree — is a guarantee. Satellite data is delayed. AIS has coverage gaps. Night lights are coarse. Earthquakes don't cause tailings failures by themselves. Every fused signal is a probability, not a certainty. Clients must layer their own domain expertise on top. The system gives you the picture; the human makes the call.

📐

The 3-source rule: As a general principle, an inference is actionable when 3 or more independent data sources agree on the same narrative. Two sources agreeing is a hypothesis. Three sources agreeing is a signal. Five sources agreeing is a decision. This is why God's Eye View fuses 100+ sources — the more you cross-reference, the narrower the confidence interval becomes.

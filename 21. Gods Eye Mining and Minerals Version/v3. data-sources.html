Source index

Every linked source on this page, alphabetically, with the layers that use it. Built automatically from the tables above.

On accuracy. Coordinates, tonnages, and classifications above are approximate and change as operations open, close, or are re-estimated. Several fields — camera orientation, disturbance footprints, and all haul traffic — are explicitly modeled or simulated rather than observed, and the console labels them as such wherever they're shown. This page describes the kind of source each field would draw from; it is not a live feed of any of these providers.

On links. All links open third-party sites. Providers move, rename, and restructure pages, so a deep link can go stale; the domain shown under each link is the stable part. Check each provider's license and terms before redistributing data — OSM is ODbL, USGS products are generally public domain, and commercial feeds (AIS, Google, exchange prices, S&P, Fastmarkets) carry their own restrictions.

ACLED — Armed Conflict Location & Event Data Free · Reg

Gold-standard disaggregated conflict dataset. Records precise dates, locations, actors, and event types for political violence and protests globally. Africa coverage from 1997; weekly updates within days of events. 230+ countries. Used by UNHCR, OCHA, and ICG. Free API key via myACLED account.

REST API CSV XLSX

GDELT Project — Global Knowledge Graph Free

Largest open spatio-temporal dataset in existence. Archives 215+ years of global news into structured event, person, location, and tone records. Raw CSV download (2.5TB+/year) or query via Google BigQuery. Especially powerful for mining protest signals, government action events, and supply chain disruptions in West Africa.
